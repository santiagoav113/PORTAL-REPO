# PORTAL-REPO

Repositorio corporativo para documentar y gestionar desarrollos, configuraciones e integraciones del portal Meta4 / Cegid PeopleNet.

## Propósito

Este repositorio está destinado a centralizar los cambios y la documentación relacionados con el portal, incluidos los desarrollos JSP mencionados en la descripción original del proyecto.

## Contenido actual

En el estado actual del repositorio solo están disponibles este README y el archivo `.gitignore`. No hay código fuente ni archivos de configuración de la aplicación en este checkout, por lo que no se pueden documentar todavía instrucciones verificadas para instalar, compilar o ejecutar el portal.

## Control de versiones

Usa ramas y commits para organizar los cambios. Antes de subir archivos, comprueba que no incluyan credenciales, datos personales ni configuración sensible. El `.gitignore` excluye, entre otros, archivos temporales, resultados de compilación y archivos `.env`.

## Tecnologías

- Meta4 / Cegid PeopleNet
- JSP (según la descripción del proyecto)
